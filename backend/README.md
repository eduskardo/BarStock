# 🍽️ Proyecto Bar - Sistema Integral para Restaurantes

Sistema completo de gestión para bares y restaurantes desarrollado con Flask, PostgreSQL y JavaScript.

## 🚀 Tecnologías
- **Backend:** Python, Flask, Flask-SocketIO, SQLAlchemy
- **Base de Datos:** PostgreSQL
- **Frontend:** HTML5, CSS3, Vanilla JavaScript, Jinja2
- **Autenticación:** JWT (JSON Web Tokens)

## ⚙️ Instalación Local
1. Clonar el repositorio.
2. Crear un entorno virtual: `python -m venv .venv`
3. Activar el entorno: `.venv\Scripts\activate` (Windows)
4. Instalar dependencias: `pip install -r backend/requirements.txt`
5. Copiar `.env.example` a `.env` y configurar las credenciales de PostgreSQL.
